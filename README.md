# Writing Skills Trainer — LK English (C1)

A single, self-contained HTML page for training writing skills in upper-secondary English:

- **Sentence structure** — combine choppy clauses into varied, hierarchical sentences
- **Verb precision** — replace weak, all-purpose verbs with vivid, exact ones
- **Cohesion** — link ideas with the connector that matches the logical relation

Each area has auto-graded recognition tasks (instant feedback + rationale), open production
tasks (model answer or automatic hints), and **endless, procedurally generated practice**.

## Use it

**▶ Open in your browser:** https://stefanwjvenekamp-cloud.github.io/writing-skills-trainer/

Or download `index.html` and open it locally — no server, no dependencies, works offline.
Append `?test=1` to the URL to run the built-in self-tests.
